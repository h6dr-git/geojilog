## ⚙️ 코드 (앱이 돌아가는 데 필요 — 함부로 옮기거나 지우면 안 됨)

| 위치 | 역할 |
|---|---|
| `client/` | 앱 화면(프론트엔드) — React |
| `server/` | 서버(백엔드) — API·AI 분석·로그인 |
| `shared/` | 클라이언트·서버 공용 상수 |
| `drizzle/` | 데이터베이스 스키마·마이그레이션 |
| `local.db` | **로컬 데이터베이스 (지우면 기록 날아감!)** |
| `uploads/` | 사용자가 올린 사진 저장소 |
| `dist/` | 빌드 결과물(자동 생성 — 지워져도 다시 만들어짐) |
| `node_modules/` | 설치된 라이브러리(자동 생성) |
| `patches/` | 라이브러리 패치 |
| `package.json` · `pnpm-lock.yaml` | 프로젝트 정의·의존성 목록 |
| `*.config.ts` · `tsconfig.json` · `components.json` · `railway.json` | 빌드·배포 설정 |
| `.env` | **비밀 키(API 키 등 — 절대 공유 금지)** |
| `.git/` · `.gitignore` 등 숨김 파일 | 버전 관리·도구 설정 |

## 자주 쓰는 명령어

```bash
pnpm dev    # 개발 서버 켜기 → 브라우저에서 localhost:3000
pnpm check  # 타입 검사
pnpm test   # 테스트
```
